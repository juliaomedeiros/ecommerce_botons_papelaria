## Problemas Identificados no Regressivo de Código

### Problema 1: Crash de Renderização (Tela Branca) no Admin (`AdminDashboard.jsx`)
- **Sintoma:** Ao acessar ou atualizar (F5) `http://localhost/admin`, o navegador renderiza uma página totalmente em branco.
- **Causa Raiz:** Quando o token armazenado em `localStorage` expira ou quando a API retorna erro (401/403), a função `fetchDashboardStats` falha ou não atualiza `dashboardStats`. Durante a renderização, a chamada a `.toFixed(2)` em propriedades indefinidas (como `dashboardStats.total_sales.toFixed(2)`) lança um `TypeError` não capturado que destrói a árvore React.

### Problema 2: Falta de Tratamento de Token Expirado (401/403)
- **Sintoma:** Se o token expira, o Admin não desloga o usuário e continua tentando renderizar a área privada.
- **Causa Raiz:** As funções de busca (`fetchDashboardStats`, `fetchProducts`, etc.) não limpavam o `localStorage` nem chamavam `handleLogout()` ao receber respostas HTTP 401 ou 403.

### Problema 3: Aba do Livro Razão Ausente na Barra Superior de Navegação
- **Sintoma:** A aba `stock_history` funcionava internamente, mas não possuía botão correspondente na barra superior de navegadores do Admin, tornando a navegação confusa.
