🛠️ Plano de Correção: BUG-010

Severidade: HIGH / P0

Contexto: integracoes-e-configuracoes | ID Canônico: BUG-20260810-CFG1-persistencia-chaves-integracao

1. Resumo do Defeito e Causa Raiz

Sintoma: Na aba Integrações do Painel Admin, as chaves salvas do Mercado Pago e Evolution API perdem os valores nos campos ao recarregar, e os campos permanecem constantemente editáveis em vez de ficarem desabilitados e protegidos.

Causa Raiz Confirmada: O configController.js expunha chaves privadas via GET /api/config público e não sanitizava o retorno do PostgreSQL. Além disso, faltava o endpoint protegido GET /api/admin/config com autenticação JWT e os estados no React (isEditingMp, isEditingEvo) para travar os campos em modo leitura/desabilitado.

2. Estratégia de Correção

Estratégia Escolhida: Persistência em PostgreSQL + Endpoint Protegido + Trava Visual de Edição no Admin (Bloqueado/Salvo vs Editar).

1. Criar endpoint protegido GET /api/admin/config com JWT Admin para carregar credenciais reais do PostgreSQL.

2. Ocultar dados sensíveis no GET /api/config público (preservando apenas chaves públicas necessárias).

3. Adicionar trava visual com botões "🔓 Editar Integração" / "💾 Salvar Integração" em AdminDashboard.jsx que mantém os campos desabilitados e protegidos após salvar.

3. Change Set Proposto

CHG Tipo Artefato Propósito
CHG-001 code backend/src/controllers/configController.js Criar getAdminConfig seguro e sanitizar getConfig público.
CHG-002 code backend/src/server.js Registrar rota protegida GET /api/admin/config com verifyToken e requireRole(['admin']).
CHG-003 code frontend/src/components/AdminDashboard.jsx Adicionar trava visual (isEditingMp, isEditingEvo) e campos desabilitados em modo leitura.
