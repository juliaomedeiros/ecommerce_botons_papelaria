🛠️ Plano de Correção: BUG-009

Severidade: HIGH / P0

Contexto: notificacoes-whatsapp | ID Canônico: BUG-20260810-WA02-evolution-404-instance-name

1. Resumo do Defeito e Causa Raiz

Sintoma: Pedidos finalizados chegam na fila de produção, mas notificações no WhatsApp do Admin e Cliente falham com erro HTTP 404 nos logs do Evolution Go.

Causa Raiz Confirmada: O whatsappService.js fazia requisições HTTP para a Evolution Go com a string de instância fixada como /tutaspaper. A instância conectada no contêiner possui o ID/nome dinâmico 67076b2d-edce-4f7f-8478-7c7eb38cc27d, fazendo a Evolution Go retornar HTTP 404 Not Found.

2. Estratégia de Correção

Estratégia Escolhida: Resolução Dinâmica de Instância e Envio Real.

1. Criar função getActiveEvolutionConfig() para ler store_config do PostgreSQL e consultar GET /instance/all na Evolution Go para auto-detectar o nome/ID da instância conectada.

2. Substituir a string fixa /tutaspaper em todos os endpoints da fila pelo nome dinâmico da instância conectada.

3. Remover a restrição rígida de NODE_ENV === 'production'.

3. Change Set Proposto

CHG Tipo Artefato Propósito
CHG-001 code backend/src/services/whatsappService.js Implementar resolução dinâmica de instância via store_config / GET /instance/all e remover URLs fixas.
