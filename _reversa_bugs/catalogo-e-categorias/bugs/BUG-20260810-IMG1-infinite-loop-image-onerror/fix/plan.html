🛠️ Plano de Correção: BUG-008

Severidade: HIGH

Contexto: catalogo-e-categorias | ID Canônico: BUG-20260810-IMG1-infinite-loop-image-onerror

1. Resumo do Defeito e Causa Raiz

Sintoma: Milhares de requisições HTTP em loop no DevTools (ultrapassando 8500 requisições) para https://images.unsplash.com/... travando o navegador ao carregar imagens de produtos no Admin e no Catálogo.

Causa Raiz Confirmada: O manipulador onError nas tags <img> do React reatribuía o e.target.src para a imagem fallback do Unsplash sem anular e.target.onerror = null. Quando a imagem substituta também sofria erro de carregamento (CORS/rede), o evento disparava recursivamente em um loop infinito.

2. Estratégia de Correção

Estratégia Escolhida: Correção Direta Cirúrgica.

1. Anular e.target.onerror = null; antes de definir o fallback em todos os manipuladores de imagem do projeto.

2. Garantir a correta resolução e persistência da imagem enviada via upload no formulário de produtos do Admin.

3. Change Set Proposto

CHG Tipo Artefato Propósito
CHG-001 code frontend/src/components/AdminDashboard.jsx Adicionar e.target.onerror = null e validar atribuição de foto no produto
CHG-002 code frontend/src/components/Catalog.jsx Adicionar e.target.onerror = null na imagem de fallback do catálogo
CHG-003 code frontend/src/components/BottonMockupDisplay.jsx Adicionar e.target.onerror = null na imagem do mockup 3D
CHG-004 code frontend/src/components/ProductDetailModal.jsx Adicionar e.target.onerror = null no modal de detalhes do produto
